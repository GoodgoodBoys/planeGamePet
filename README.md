# Plane Game Pet

Windows 桌面悬浮飞机宠物与双人联网小游戏测试版。

## 当前测试包

- 版本：0.6.5
- 下载：[PlanePet-Public-Single-0.6.5.zip](releases/PlanePet-Public-Single-0.6.5.zip)
- 校验：[PlanePet-Public-Single-0.6.5.sha256.txt](releases/PlanePet-Public-Single-0.6.5.sha256.txt)

下载并解压 ZIP 后，双击 `PlanePet.exe` 即可运行。首次运行和匹配、邀请、对战、快捷表情等联网功能需要连接互联网。

> 这是面向体验验证的 Windows 测试版本。如 Windows SmartScreen 提示未知发布者，请先核对 SHA-256 校验值，确认文件来源后再决定是否运行。
